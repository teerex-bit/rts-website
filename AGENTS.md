# Reforming the Soul static site

- Keep the production site framework-free: semantic HTML, shared CSS, and minimal vanilla JavaScript only.
- Ordinary text and controls must remain live HTML. Keep visual assets independently replaceable.
- The authoritative journey is **Awaken → See Clearly → Become → Join**. Never add Walk as a separate stage.
- Record absent approved artwork in `docs/asset-manifest.md`; never source material from the legacy repository.
- Test every new page at desktop, laptop, tablet, and mobile widths.
