# Brand system

The public site is a collection of static route documents with stylesheets linked by each page; there is no current `global.css`. Inspect the route's linked stylesheets before changing shared-looking styles. Existing colors include navy (`#06233a`), cream (`#f7f2e9`), olive (`#607548`), and gold (`#c78b32`). Georgia is used for major headings and quotations, with Arial used for navigation, controls, labels, and body copy.

Shared elements are implemented in current assets such as `public/assets/css/public-header-navigation.css`, `public/assets/css/public-footer-branding.css`, and `public/assets/site.js`, alongside route-specific CSS. There is no current `components.css`; verify actual page references before editing a component style.

The authoritative progression is **Awaken → See Clearly → Become → Join**.
