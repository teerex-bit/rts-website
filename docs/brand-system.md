# Brand system

The shared tokens in `global.css` establish navy (`#06233a`), cream (`#f7f2e9`), olive (`#607548`), gold (`#c78b32`), ink, paper, spacing, and readable maximum widths. Georgia supplies the elegant serif voice for major headings and quotations; Arial supplies navigation, controls, labels, and body copy until approved font files are supplied.

Shared focus outlines are deliberately high contrast. The reusable header, buttons, journey, course shell, cards, quotations, and navy panels live in `components.css`.

The authoritative progression is **Awaken → See Clearly → Become → Join**.
