# Deep Dive publication

Public, unlisted entry: `/deepdive` (also `/deepdive/`). No navigation or sitemap entry. HTML robots metadata and HTTP X-Robots-Tag request no indexing. This is an unlisted public URL, not password-protected access.

The 25 approved narrative screens and original landscape photographs are derived from `teerex-bit/rts-deep-dive`, commit `20e3fb9`. Production uses static semantic HTML, CSS, and vanilla JavaScript; React and Next.js are not shipped. Existing titles, teaching, Scripture, stage labels, and photograph assignments are preserved. JavaScript handles screen navigation, expandable teaching, and browser-local progress/reflection persistence. Nothing is sent to a server.
