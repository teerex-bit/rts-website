# Page build rules

1. Use semantic, formatted HTML and link the global, component, and page stylesheet.
2. Keep navigation, headings, paragraphs, cards, quotations, labels, and buttons in HTML.
3. Keep every logo, icon, photo, botanical, illustration, and complex scene as an independently replaceable file.
4. Never bake ordinary copy or controls into artwork.
5. Do not add frameworks, build tools, account state, databases, or LMS behavior.
6. Verify keyboard operation, focus visibility, internal links, image loading, overflow, and responsive layout.
7. Do not use the review hub in public navigation.
