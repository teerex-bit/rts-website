## Shared templates and alignment

- **Hero and stage landing:** Pages 01, 02, 07, 13, 18, and 30 share header, journey rail, editorial panel, scenic container, and CTA alignment.
- **Course lesson:** Standard content width, progress sidebar, reading column, practice block, and closing CTA are shared across instructional pages.
- **Reflection, practice, workbook, and closing:** The lesson frame adds appropriate live quotation or practice treatments without baking copy into imagery.
- **Library and invitation:** Pages 37–40 use aligned resource/CTA layouts.
- Scenic art uses responsive cover-style containers; logos, icons, and botanical art are independent SVG assets using contained proportions. No reference PNG is stretched, cropped, modified, or shipped as a page background.

## Editing model

Page titles, routes, stages, template selections, and body summaries live in `src/pages.js`; global destinations live in `src/links.js`. Shared components are emitted by `scripts/build.js`, while colors, alignment, breakpoints, and component styling live in `src/assets/styles.css`. Run `npm run build` after edits.
