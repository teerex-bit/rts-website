# Visual page-family implementation plan

## Method and guardrails

All 41 PNGs in `done/` were visually inspected at full-page scale and as a comparative contact sheet. The numbered filename, rather than dimensions, determines sequence. `22 Becoming  1 - 2B  (1).png` is a duplicate reference and not a 41st page. Page 01 is now implemented; Pages 02–40 are intentionally still on the provisional generator pending family-by-family implementation. Ordinary copy, navigation, controls, cards, quotations, and diagrams will be HTML; reference imagery is used only as replaceable artwork. The approved journey remains **Awaken → See Clearly → Become → Join**.
